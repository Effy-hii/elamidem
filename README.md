# לומדים יחד — הדמיית מאגר

אתר סטטי בעברית להצגת רשימות בתי ספר וקהילות לפי אזור, עם חיפוש לפי סמל מוסד ועמודת אנשי קשר.

## עותק מקומי

`build-data.py` קורא את קובץ המקור `רשימה מאוחדת בתי ספר וקהילות (1).xlsx` שנמצא בתיקיית העבודה שמעל תיקיית האתר. הוא מייצר:

- `data.js` — כל הרשומות ואנשי הקשר, לשימוש מקומי בלבד. הקובץ מוחרג מ־Git.
- `public-data.js` — שמות, סמלי מוסד ואזורים של בתי הספר בלבד, ללא פרטי קשר או רשימת קהילות. זה הקובץ שנכלל במאגר הציבורי.

כאשר האתר נפתח מ־`localhost` או מקובץ מקומי, הוא טוען את `data.js` המקומי. באתר מרוחק נטענת `public-data.js`.

## פתיחה מקומית

פתחו את `index.html` בדפדפן או הפעילו שרת סטטי מתוך התיקייה.

## קבצים

- `index.html` — בחירה בין בתי ספר לקהילות.
- `schools.html` — חיפוש וסינון בתי ספר.
- `communities.html` — חיפוש וסינון קהילות.
- `app.js`, `style.css` — התנהגות ועיצוב משותפים.
